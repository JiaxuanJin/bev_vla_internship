## 5. 图像用途与注意事项

| 图像 | 最适合用于 |
|---|---|
| 六路相机拼图 | 解释 DriveLM → nuScenes 的 sample token 对齐 |
| BEV 通道图/热力图 | 介绍 BEV Encoder 输出与特征表达 |
| 检测结果 | 说明 3D 目标框和 BEV 预测可视化脚本 |
| 地图真值 vs 预测 | 展示真实 mIoU 评估对象、已有局限 |

复制到 GitHub 时只提交**必要图片**，不提交整个 `outputs/` 大目录，也不必包含原始上万张相机图片或权重文件。
