## 实测结论

已真实完成 **20 次 GPU optimizer.step**，由地图记录实例与真实几何位置共同决定
Attention 监督目标，保留真实 Detection、Segmentation、Attention 三项计算图。
独立验证的相关区域分割 IoU 从 **34.17523061% → 34.18191452%**，
增加 **0.00668391 个百分点**（相对约 **0.01956%**）。
这个变化非常小，错误/置乱指令还略高于正确指令，不能视为可靠的语言定位收益。

另建立了独立车辆/行人方位指令协议，真实计算非官方 **AP@2m_xy**：
Relevant AP 从 **66.53614842% → 66.52792515%**，
下降 **0.00822326 个百分点**。地图语言的空间训练没有带来对象指令检测收益。
地图指令本身没有对应的 3D 检测目标，地图指令 Detection AP 仍是 `NOT_EVALUABLE`。

没有根据验证结果重选样本、改变阈值、续加训练步数或修改模型以制造正向提升。

## 实例标注、有效数量和物理坐标

使用历史预先固定的 20 个 Train / 6 个 Val 帧索引，枚举 Divider、Crosswalk 两类及
front-left/front-right/rear-left/rear-right 四象限，共 208 条候选。
方位来自 Ego 米制坐标（x 向前、y 向左），实例来自 nuScenes 真实地图 record token。
Crosswalk 两条长边按同一个 polygon record 合为同一实例；Boundary 是 road/lane union
轮廓，无法可靠分配唯一原始记录 ID，本轮不伪造 Boundary 实例监督。

同一象限存在多个同类 record 时全部拒绝，未选择最近或猜测目标。
最终 **30 条 Train（14 帧、7 场景）/10 条 Val（4 帧、2 场景）**有效；
80 条 `AMBIGUOUS`、88 条 `TARGET_ABSENT`。
验证原固定 6 帧仍全部检查，另外 2 帧没有可接受的地图实例指令；所有拒绝记录均保留。
有效验证中只有 **2/10** 条存在其他同类 record，干扰实例指标的证据范围有限。

[annotations_v2/manifest.json](../../outputs/stage2_spatial_20261026/annotations_v2/manifest.json)

```text
M_target = (GT == target_class) ∩ fixed_ego_quadrant ∩ selected_map_record_raster
```

复用原作者矢量提取、折线采样、厚度和类别优先级，保留 record ID 后核对矢量次序及坐标。
六帧重新生成的完整 `200×400` GT 均与历史 NPZ **逐像素相同**；没有 resize、旋转或翻转 GT。

GT 栅格为 Ego x∈[-30,30]、y∈[-15,15]、0.15 m/像素。
原生 `150×150` BEV 的位置契约来自作者 reference points `(col+.5)/W,(row+.5)/H`，
物理范围 [-51.2,51.2] m。将 GT 像素中心经逐帧 Ego→LiDAR 标定变换后使用
`grid_sample(align_corners=False)` 采样 Attention logits；保留可微计算图。
这属于已知坐标的物理投影，不是直接 resize GT。

米制坐标斜坡核验最大误差 `2.1316282e-14 m`；旧转置/翻转/cropper 对应坐标与该标定投影
的平均差为 **0.89963886 m**。新 Attention 监督和全部新 A/B Attention 评价统一使用标定投影。
作者 Segmentation Head 的历史变换及权重保持原样；不能据此宣称整个作者模型的配准问题已全部解决。

## 独立对象指令 Detection AP

地图 Divider/Crosswalk/Boundary 与汽车/行人3D GT没有实例对应，故地图指令 AP 保持 N/A。
额外独立定义 `Find cars/pedestrians on the front/rear left/right`，明确选择象限内
**全部同类真实对象的集合**，不从多实例里猜一个目标。
新 schema 位于独立 `spatial_detection.py`，原地图解析器不变。
对象指令经独立 schema 校验后使用 DistilBERT 编码，不伪装成地图类别。

固定原6帧×2类×4象限=**48条**，包含15条相关GT为空的负例指令。
真实3D GT几何中心经标定及ego pose变换后唯一匹配 `sample_annotation`，最大误差
`3.49871185e-6 m`，并确认类别为 vehicle.car / human.pedestrian.*。

[instance_provenance.json](../../outputs/stage2_spatial_20261026/object_metrics/instance_provenance.json)。

## 原因分析、边界和下一步

1. 已证实真实空间监督训练可执行，目标由真实 map record 与位置共同决定；没有退回全类别标签。
2. 20条训练指令、13帧、7场景和10条验证指令的规模很小，ROI重复计权，
   约0.0067个百分点的IoU变化不能证明泛化收益，也没有显著性结论。
3. 新空间模型和历史类别模型使用相同初始化及20次更新，但训练文本、有效样本选择、
   监督与Attention投影不同。A/B是同条件验证，**不是仅改变监督形式的训练消融**。
4. 简单通道查询与冻结DistilBERT对方位的响应不足；错误/置乱指令没有稳定劣于正确指令。
   同类其他实例质量分数反而增加，说明尚未学会唯一目标选择及干扰抑制。
5. Fusion残差alpha仍约0.0041，检测/分割输出变化很小。冻结作者分割头还保留历史坐标变换，
   与新物理Attention监督存在任务协同限制。不能在本次验证后继续调整协议再挑结果。
6. 下一阶段应另建预注册训练/验证协议：扩大真实可消歧实例覆盖，单独训练/验证方位与对象指令，
   对比等样本、等步数、相同投影的类别/空间监督；保持本次数据和结果冻结。
