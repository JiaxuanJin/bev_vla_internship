# 第二阶段：核心模块设计与实现

> 来源：本次验收于 2026-10-21 提供的指导老师原始任务书。以下按提供的原文完整保存；最终验收不以二次整理文档替代原文。

核心目标： 完成语言引导BEV注意力增强模块的设计与代码实现。

## 一、详细任务

### 1. 语言编码器与语义解析模块实现

- 集成轻量级DistilBERT作为语言编码器，加载预训练权重。
- 实现自然语言指令的预处理和编码功能，提取指令语义特征。
- 设计语义-空间映射头，将一维语言特征转换为二维BEV空间特征。
- 编写单元测试，验证各子模块的输入输出正确性。

### 2. 注意力生成与融合模块实现

- 设计空间注意力生成器，将语义-空间特征转换为BEV注意力掩码。
- 实现注意力融合机制，将生成的掩码与原始BEV特征进行加权融合。
- 设计多任务损失函数（检测损失+分割损失+注意力正则化损失）。
- 将增强模块集成到BEVFormer的特征提取流程中，确保代码可运行。

## 二、阶段产出

1. 语言引导BEV注意力增强模块的完整代码实现。
2. 模块结构设计文档（包含架构图、各子模块功能说明）。
3. 集成了增强模块的完整BEV感知系统代码。
4. 单元测试报告，验证各模块功能正确性。

## 三、执行要求

1. 逐项核对以上8项详细任务和4项阶段产出，明确PASS、FAIL或NOT_VERIFIED。
2. 以实际源码和测试结果为依据，缺失功能直接补齐，不得以文字描述代替代码实现。
3. 优先验证新增统一入口的真实运行能力，不能用旧实验结果冒充新入口测试。
4. 不擅自增加师傅未要求的强制验收条件；语义定位精度、mIoU提升及空间协议等额外研究问题单独记录。
5. 生成中文最终验收报告，并将原始任务书完整保存至docs/stage2/，作为后续验收依据。
