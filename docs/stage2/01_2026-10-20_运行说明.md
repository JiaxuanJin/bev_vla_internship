# 阶段二 Day 1 运行说明（2026-10-20）

## 工作范围

完成 DistilBERT 文本编码、padding mask、masked mean pooling、768→256 维语义投影的接口实现与测试。
本阶段模块不包含真实 BEVFormer 特征融合，也不代表注意力已经接受训练。

## 文件

- `stage2/language_encoder.py`：加载本地语言模型，句级语义池化与 batch 编码。
- `stage2/semantic_projection.py`：768→256 维投影层。
- `stage2/tokenizer_config.json`：预训练模型版本与 tokenizer 参数。
- `scripts/stage2/download_distilbert.py`：固定 commit 下载 safetensors，核对模型 SHA256。
- `scripts/stage2/run_day1.py`：真实预训练权重 + 两条指令的执行与梯度检查。
- `tests/stage2/test_stage2_day1.py`：不下载权重的 shape、mask、梯度、异常输入测试。
- `requirements_stage2.txt`：阶段二增量依赖，不重装 torch/MMCV。

## 执行顺序

```bash
cd ~/projects/bev_vla
python -m pip install -r requirements_stage2.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m pytest tests/stage2/test_stage2_day1.py -q
HF_ENDPOINT=https://hf-mirror.com python scripts/stage2/download_distilbert.py
python scripts/stage2/run_day1.py --device auto
```

若镜像下载不可用，只把 `HF_ENDPOINT=https://hf-mirror.com` 去掉，下载同一仓库、同一 revision；不修改模型哈希要求。

## 输出与验收

- `outputs/stage2/2026-10-20/model_download_manifest.json`：模型来源、固定版本、权重 SHA256。
- `outputs/stage2/2026-10-20/day1_smoke_test.json`：真实模型运行记录、向量形状、padding 与梯度检查。
- `outputs/stage2/2026-10-20/semantic_projection_init.pt`：随机初始化的投影层参数，不是训练后权重。

验收要点：单测全部 PASS；下载模型 SHA256 匹配；真实模型生成 `(B,768)`，投影得到 `(B,256)`；投影层梯度 L1 大于 0。

模型缓存与原始运行记录保存在本地，不上传大权重；最终 Logbook 统一记录当天运行结果。
