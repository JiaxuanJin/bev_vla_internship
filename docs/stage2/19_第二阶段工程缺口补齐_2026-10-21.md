## 1. 三个工程缺口及实现

| 缺口 | 本轮实现 | 已验证边界 |
|---|---|---|
| 自然语言预处理与特征提取 | 空白规范化保留否定/方位；受约束多目标/同义解析；拒绝未知对象、含糊否定、冲突方向；本地冻结 DistilBERT + mask 池化 | 解析、编码、padding、置乱与冻结行为可测；不代表学会语义定位 |
| 一维语义到二维 BEV | q[B,256] 与视觉各位置相似度产生 A[B,1,H,W]，显式返回 S=q*A[B,256,H,W]；残差 F+αF*A 不变 | 非方形序列/网格、位置响应、米制中心及标定变换测试通过；地图 GT 配准仍未闭环 |
| 工程集成 | Stage2Pipeline + run_stage2.py 组合动态语言、投影、Attention、Fusion、共享 BEV 双 Head；原始/旁路/增强三次同帧对照 | 统一入口真实前向通过；不是完整时序训练、正式部署或精度提升 |

## 4. 统一复现命令

从项目根目录运行；输出已存在时拒绝覆盖，重复执行需换新路径。CPU 依赖使用项目既有环境；真实双 Head 必须在可访问 GPU 的作者环境中执行。

```bash
cd ~/projects/bev_vla

# 原有与新增测试，不加载真实模型或数据集
.venv-bevformer/bin/python scripts/stage2/run_stage2.py --mode cpu-tests \
  --output outputs/stage2_completion/reproduce_cpu.json

# 本地预训练 DistilBERT + 真实 BEV 缓存；不重新运行图像主干
.venv-bevformer/bin/python scripts/stage2/run_stage2.py --mode offline-bev \
  --device cpu --output outputs/stage2_completion/reproduce_offline.json

# 动态指令 → 共享 BEV → 检测/分割双 Head，原始/旁路/增强对照
~/projects/bevformer_author_clean_5080/.venv-author/bin/python \
  scripts/stage2/run_stage2.py --mode joint \
  --text 'Find lane markings ahead' \
  --joint-checkpoint /mnt/g/nus/bevformer_small_joint_author.pth \
  --output outputs/stage2_completion/reproduce_joint.json
```

`--model`、`--bev`、`--author-root`、`--joint-config`、`--joint-checkpoint`、`--index` 可显式指定本地路径/样本；`offline-bev` 可重复指定 `--text`，真实单帧 `joint` 严格只接受一条，禁止静默丢弃或隐式广播。默认不联网下载，不加载训练后的语言融合权重；当前融合层随机初始化。
