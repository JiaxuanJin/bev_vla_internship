## 先看结论

现有证据支持工程链路可运行，尚不支持“语言增强已经带来可靠的整体精度收益”。Step65 用更高的背景误检换来部分前景 IoU 增长；Step66 背景保护后的前景召回下降；Step67 在 Mini Train 校准集按既定规则选择了 original 回退。正常文字在已训练模块上没有稳定胜过置乱文字。

当前不宜仅扩大迭代次数就宣称值得继续训练。若继续投入，应先解释低基线及空间评估协议，并用训练集设计修正、固定验证协议和语言负对照判断改善；本次没有做任何参数选择、阈值调优或训练。单帧展示仅帮助定位问题，不能替代独立场景评估。

## 数据和计算口径

- 数据为 nuScenes v1.0-mini Mini Train / Mini Val；Mini Val 的不同 token 子集仍来自同一小规模场景体系，不是独立数据集。
- 类别 ID：0 Background，1 Divider，2 Ped Crossing，3 Boundary。全部分割指标用原始四类 argmax，按全子集像素累计混淆矩阵后计算，未平均逐帧 IoU。
- IoU = TP/(TP+FP+FN)；前景 mIoU 是类别1–3平均；四类 mIoU 是类别0–3平均。
- P¹/R¹ 是“保持类别正确”的三前景类微平均：P=ΣCkk(k=1..3)/所有预测前景像素，R=ΣCkk(k=1..3)/所有GT前景像素。前景之间分错类也计入错误。
- 若某类既无 GT 也无预测，其 IoU 未定义；平均数只包含定义的类别，单帧缺类情况以 JSON 的 null 为准。
- CSV/JSON 另含每一类 Precision/Recall，以及忽略前景类别的二值前景 P/R（binary），避免指标定义歧义。分母为0写空值/null，绝不补0。
- 背景误检率 = C[0,1:4]之和 / C[0,:]之和。不是 1-Background IoU，也不是所有像素误检率。
- Step54 是 81 帧时序 ON 的几何 A/B，不含语言增强；Step61/62、65–68 是时序 OFF 的独立帧。Step70/72/最新验收使用另一个 joint 双 Head checkpoint，不能和 segmentation-only checkpoint 交叉排名。
- 历史 JSON 的可复算混淆矩阵字段已校验；这项校验不等于对数据标定、原始权重来源或物理空间协议作独立认证。
