## 2. 验证命令

先执行不依赖数据集和 checkpoint 的离线 CPU 回归。本机 `.venv-bevformer` 已有 pytest 和语言模块依赖，作者隔离环境未安装 pytest：

```bash
cd ~/projects/bev_vla
.venv-bevformer/bin/python scripts/stage2/run_regression.py
```

该入口执行 8 组回归，保存环境、源码 SHA256、退出码与日志到 `outputs/stage2_regression/regression.json`。本轮结果已归档至 [regression_2026-10-21.json](../../results/stage2_2026-10-21/regression_2026-10-21.json)。其他机器需先在兼容 PyTorch 环境准备 `requirements_stage2.txt` 中的依赖，不要为运行 CPU 自检重装作者 CUDA/MMCV 环境。

以下为真实实验的复现命令；会读取本地数据和模型，并更新对应步骤的原始报告：

```bash
cd ~/projects/bev_vla
source ~/projects/bevformer_author_clean_5080/.venv-author/bin/activate

# 多任务 Loss 单元测试
python3 scripts/stage2/run_step69_loss_contract.py --self-test

# 真实共享 BEV 检测 + 分割前向（必须准备联合 checkpoint）
python3 -u scripts/stage2/run_step70_joint_integration.py \
  --audit --live \
  --joint-checkpoint /mnt/g/nus/bevformer_small_joint_author.pth \
  --index 0

# 真实检测 + 分割 + 注意力梯度检查，不更新权重
python3 -u scripts/stage2/run_step72_real_joint_gradient.py --live --index 0

# 受约束自然语言和地图锚点诊断
python3 -u scripts/stage2/run_step73_fill_gaps.py --live
```

> 运行 Step70、72 前请先检查作者历史依赖的 NumPy 别名和 Dataset/DataLoader 兼容补丁是否已按项目现有环境配置；不要修改第三方公开 checkpoint。

Step71 的 `--audit --run-tests` 是该步骤的历史报告生成入口，其状态截止 Step70，会覆盖 `docs/stage2/11～13` 和 Step71 JSON；当前回归使用上面的统一入口，当前验收状态以 Step72/73 和本轮报告为准。
