### 当前最终统一入口（建议使用）

```bash
cd ~/projects/bev_vla
.venv-bevformer/bin/python scripts/stage2/run_stage2.py --mode cpu-tests \
  --output outputs/stage2_final_acceptance/reproduce_cpu.json
.venv-bevformer/bin/python scripts/stage2/run_stage2.py --mode offline-bev \
  --output outputs/stage2_final_acceptance/reproduce_offline.json
~/projects/bevformer_author_clean_5080/.venv-author/bin/python \
  scripts/stage2/run_stage2.py --mode joint \
  --output outputs/stage2_final_acceptance/reproduce_forward.json
~/projects/bevformer_author_clean_5080/.venv-author/bin/python \
  scripts/stage2/run_stage2.py --mode joint-backward --text 'Find lane markings' \
  --output outputs/stage2_final_acceptance/reproduce_backward.json
```

`cpu-tests` 运行全部 69 项 pytest 与 7 组旧自检；`joint` 使用 Mini Val 原始/旁路/增强对照；`joint-backward` 使用 Mini Train 单帧真实三 Loss 联合反传，无 optimizer.step。两个 GPU 模式必须在可访问 CUDA 的作者环境运行，输出文件已存在时拒绝覆盖。

本轮最终实际执行使用 `outputs/stage2_final_acceptance_seeded/cpu.json`、`offline_bev.json`、`joint_forward.json`、`joint_backward.json`，命令/环境/源码哈希和日志已归档至 [最终结果目录](../../results/stage2_final_acceptance_2026-10-21/README.md)。上方 `reproduce_*.json` 为另选的新路径，不覆盖这些证据。任务依据为 [原始任务书](02_第二阶段原始任务书.md)，完整判定见 [最终验收](20_第二阶段最终严格验收_2026-10-21.md)。
