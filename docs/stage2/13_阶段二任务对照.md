# 第二阶段原始任务逐项验收对照

唯一任务依据为 [指导老师原始任务书全文](02_第二阶段原始任务书.md)。以下 8 项按原文拆分，状态仅使用 PASS、FAIL、NOT_VERIFIED。执行细节、真实数据 Loss/梯度和拟提交清单见 [最终严格验收报告](20_第二阶段最终严格验收_2026-10-21.md)。

## 8 项详细任务

| 编号 | 原始任务 | 判定 | 当前源码与本轮证据 |
|---|---|---|---|
| T1 | 集成轻量级 DistilBERT 作为语言编码器，加载预训练权重 | PASS | `language_encoder.py` 本地真实预训练权重加载；offline-bev、joint、joint-backward 动态编码，模型文件哈希核对 |
| T2 | 实现自然语言指令的预处理和编码功能，提取指令语义特征 | PASS | 空白规范化、tokenizer、padding/mask、冻结池化；多目标/同义/有限否定/方位/置乱自动测试，真实输出 [7,768] |
| T3 | 设计语义-空间映射头，将一维语言特征转换为二维 BEV 空间特征 | PASS | `SemanticProjection.forward_spatial()`：q[B,256] 与 V[B,256,H,W] 形成 S[B,256,H,W]；S 是 Attention 的真实前置输入 |
| T4 | 编写单元测试，验证各子模块的输入输出正确性 | PASS | 本轮全部相关 pytest 69 项通过，包含空间映射依赖、张量维度、坐标、输入拒绝、Hook 清理和梯度测试 |
| T5 | 设计空间注意力生成器，将语义-空间特征转换为 BEV 注意力掩码 | PASS | `LanguageBEVAttention.from_semantic(S)` 通道聚合后生成 A[B,1,H,W]，输入依赖及反向传播测试通过 |
| T6 | 实现注意力融合机制，将生成的掩码与原始 BEV 特征进行加权融合 | PASS | `F + alpha*F*A`；新入口真实双 Head 三路 bypass 最大差均为 0，旧权重键兼容 |
| T7 | 设计多任务损失函数（检测损失 + 分割损失 + 注意力正则化损失） | PASS | 新入口 `joint-backward`：Mini Train 单帧、一次真实前向三 Loss 及联合 backward；各项融合梯度有限非零，不调用 optimizer.step |
| T8 | 将增强模块集成到 BEVFormer 的特征提取流程中，确保代码可运行 | PASS | `run_stage2.py → joint_runtime.py → Stage2Pipeline` 临时共享 BEV Hook；真实 GPU 前向、bypass、联合反传均通过 |
