1. **第 3.4 节 AP 口径混写。** 原文将探索 `AP@2m_xy` 统称非插值 AP。只读封存 v1 的 `eval_metrics.py::sdk_ap` 与现有协议后，确认独立 LG-BEV 使用 101 点插值及 `min_recall=min_precision=0.1`；现与早期 V1—V5 的非插值口径分开说明，保留非官方完整 nuScenes mAP 的边界。
2. **第 4.4 节对照状态过时。** 原文仍称 A9562/Baseline 双 Head 逐张量一致性待检查，与第 8.2/8.4 节及既有 `all_a_only_heads_bitwise_equal=true` 证据冲突。改为固定 8 帧已验证，并同步第 4.5 节独立 StageB256 完成、Development 未完成状态；新增 11/03 文档复核日期，实验统计截止保持 11/02。
