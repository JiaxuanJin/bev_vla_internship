### 换机器时的规则

1. 先按清单准备非 Git 资产，明确区分仓库根、作者根、数据根、共享缓存根和独立输出根。
2. 读取既有结果只需轻量 CSV／JSON／图表；离线重计分还需相应原始预测与 manifest，不能假设 Git 仓库包含这些大文件。
3. 旧配置及协议绑定了绝对路径、源码和资产 SHA。换机器时另写路径映射／迁移记录；如路径或源码变化影响协议身份，须版本化并重新授权。不得静默编辑旧协议后继续冒称同一 SHA。
4. 训练恢复或完整离线复核还需原 receipt、execution、数据清单和封存输入，详见 `configs/main.json::sealed_inputs` 及已有训练审计；缺文件时明确停止，不补造回执。
5. 独立输出目录不得借助符号链接规避写入限制。原始数据、模型权重、GT、BEV 缓存、原始预测和 SQLite 均不上传 GitHub。
